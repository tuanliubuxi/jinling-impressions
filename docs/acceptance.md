# 手机与远程验收

使用最新生产版本。启动服务后，手机和队友均用实际可访问的地址进入；更换网络后重新启动服务。浏览器已有旧版本缓存时先重新加载页面。

| 测试 | 操作与预期 |
| --- | --- |
| 正常生成 | 输入“半天在科巷逛吃，不看景区”；提交后页面不跳转、不清空输入，行程实际安排科巷。 |
| 条件组合 | 输入“带老人，少走路，看湖景和城市生活”；每天主要站点不超过两处，不强排登山。 |
| 日期冲突 | 选择2026-11-23，输入“只去南京博物院”；提示常规闭馆并调整日期，不调用模型。改为两日并增加玄武湖，应把博物院放到第二天。 |
| 需求覆盖 | 输入“想看明孝陵，也想逛商场”；两个需求都成为主要站点；雨天仅室内时不暗加户外游览。 |
| 重复与刷新 | 生成中重复点击、刷新、暂停后继续查看，应恢复同一任务；完成后刷新、切换历史版本不会新增模型用量。 |
| 修改 | 从已有行程修改为“去掉明孝陵，只保留购物和休息”；生成一个新版本，原版本仍可查看。 |
| 异常恢复 | 生成中断网后重连，继续查询原任务；错误明确显示，不循环调用模型。需要再次生成时由用户主动操作。 |
| 图文 | 手机打开探索页、搜索、筛选、进入详情、切换与放大图片；图片不溢出，关闭放大后可继续操作。 |

遇到问题请记录：手机与浏览器、操作步骤、出游条件、发生时间、页面提示，以及刷新前后任务是否一致。不要附 API Key。规划费用为参考，未来开放与预约余量仍需官方核实。
